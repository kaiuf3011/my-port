(Engineering deep-dive)

RGU AI Assistant — how a query flows.

01User query
02Intent classifier
03Exact-match router
04Hybrid retrievalChromaDB + Fuse.js
05Grounded LLM answer

The problem

Pure semantic search was contaminating results: short acronyms (department and course codes) matched the wrong documents because embeddings treat them as near-synonyms. Students got confident answers about the wrong program.

What I built

An exact-match routing layer that catches known entities and acronyms before vector search, plus sparse (keyword) retrieval via Fuse.js blended with ChromaDB results. Conversation state carries context between turns, and a fallback path responds honestly when retrieval confidence is low.
